# 模試の弱点復習

ホームの「模試の弱点復習」から「復習する (件数)」で開始する。
直近10回の模試の誤答を問題IDでまとめ、全ジャンルまたは選択したジャンルの新しい誤答から最大15問を出題する。
件数は15問への切り詰め前の、出題可能な未卒業問題数。対象が0件なら入口を表示しない。
問題集に存在しなくなったIDは出題対象から除外する。

クイズは既存の `MainView` / `QuizSessionViewModel` を再利用する。
模試復習の場合だけ専用フラグを渡し、選択済みの最大15問をそのまま使う。
同じ語でもジャンルや問題IDが違えば別問として扱う。
誤答はセッション内で再出題し、正解時に即座に卒業状態を保存する。
途中終了しても正解済みの問題は卒業を維持し、誤答・未回答の問題は残る。
全問正解後は「復習完了！」と、取り組んだジャンル数を表示する。

## 保存データ

- `examResults_v1` と `ExamResult` / `QuestionAttempt` の形式は変更しない。
- 旧データに `attempts` がない場合も、既存の `wrongQuestionIDs` から問題を解決する。
- 卒業状態は新しい `examReviewedMistakes_v1` に「問題ID → 卒業した最新誤答の模試結果UUID」として保存する。
- 同じ問題を後の模試で再び間違えた場合は結果UUIDが変わるため、復習対象に復帰する。
- 模試履歴のリセットで卒業状態も削除する。
- 模試の採点・道場モード・従来の学習記録による「弱点復習」は既存の動作を維持する。

集計範囲の既定値は `ExamResultRepository.reviewExamLimit`、1セットの上限は `reviewQuestionLimit`。
リポジトリの集計・セッション生成APIでは `recentExamCount` を指定できる。

## 検証

`ExamMistakeReviewTests` で集計範囲、ジャンルフィルタ、重複排除、15問上限、卒業の保存・再発、旧形式の読み込み、模試履歴の不変性、誤答の再出題、通常練習の分離を確認する。

iPhone SE（第3世代）／iOS 27.0シミュレーターで、既存テストを含む139件が成功した。
別の検証用シミュレーターに誤答1件を用意し、ホームの件数表示・ジャンル選択メニュー・既存クイズへの遷移・正解後の専用完了画面・ホームに戻った後の入口非表示も画面上で確認した。
