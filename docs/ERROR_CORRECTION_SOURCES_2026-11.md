# 誤字訂正 問題拡充の出典（2026-11-01）

誤字訂正を 1ステージ14問から5ステージ75問へ拡充（新規61問）。ステージIDは501〜505、各15問、難度は4。準1級配当字を中心にし、基本語の表記も交えて一字の訂正を練習する。

## 確認方針

- 主な出典は日本漢字能力検定協会「漢字ペディア」。表記、読み、意味を確認した。
- 例文と解説は今回の学習用に作成・要約した。辞書の例文を転載していない。
- 訂正前後で変わるのは漢字一字のみ。誤字は文中に1回だけ現れ、置換によって訂正後の文と一致する。
- 各問は4択で正解を1つに限定。「巻土重来」「陵駕」「陵辱」「格好」「琉璃」「英知」「略奪」「肝心」などの許容表記は誤答として使わない。
- 新規61問で訂正対象の語と文を重複させず、既存501の訂正対象とも重複させない。
- 字体だけの違いは誤字として扱わない。準1級向けの構成だが、全問の全漢字が準1級配当字であるという意味ではない。
